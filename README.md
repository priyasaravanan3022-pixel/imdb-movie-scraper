# IMDb Top 250 Movie Scraper & Dashboard

A Python-based mini project designed to extract top-rated movie details from IMDb, save them into a structured CSV format, and generate an interactive web dashboard for visual analytics.

## 🚀 Features
* **Movie Data Extraction**: Scrapes IMDb Top 250 movies list including Rank, Movie Title, Release Year, and IMDb Rating.
* **Structured Output**: Saves all scraped data automatically into a clean CSV file (`imdb_top_250_movies.csv`).
* **Interactive Dashboard**: Generates a responsive HTML/CSS web dashboard with KPI metric cards and complete dataset view.

## 🛠️ Technologies Used
* **Programming Language**: Python
* **Data Manipulation**: Pandas
* **Web Scraping & Parsing**: Requests, BeautifulSoup
* **Frontend Reporting**: HTML, CSS, Bootstrap

## 📂 Project Files
* `main.py`: Core script to fetch and generate the CSV dataset.
* `dashboard.py`: Script to generate the HTML visual dashboard report.
* `imdb_top_250_movies.csv`: Structured dataset containing the top 250 movies.
* `imdb_dashboard.html`: Interactive web dashboard file.

## ⚙️ How to Run the Project

1. Clone or download this repository.

2. Run the main script to generate the dataset:
   python main.py

 3. Run the dashboard generator script:
   python dashboard.py
   
    4. Double-click the generated imdb_dashboard.html file to view the visual report in your web browser.
